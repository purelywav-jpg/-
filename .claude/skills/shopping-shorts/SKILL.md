# 쇼핑쇼츠 제작 스킬

사용자는 쿠팡 링크(+제품 이미지)를 준다. 최종물은 **사용자가 손볼 수 있는 CapCut 프로젝트**(+mp4, 썸네일 jpg).

- 다운로드 폴더(드롭 폴더): `C:\Users\IdeaPad\Desktop\클로드 영상편집 자동화\쇼핑쇼츠` (제품별 하위 폴더를 만들어도 됨)
- 산출물 복사 위치: 같은 폴더의 `완성본\`
- 스테이징(ASCII 경로, 공백/한글 금지): `C:\CapCutAssets\<제품영문명>_ad\`
- 스크립트: `scripts/build_shorts.py` (voice / build 두 단계, 설정은 JSON 한 개)

## 역할 분담 (안 지키면 안 되는 것)
| 단계 | 누가 |
|---|---|
| 로그인(틱톡/샤오홍슈 QR·전화 인증) | **사용자.** 나는 로그인·계정 생성·인증코드 입력을 하지 않는다 |
| 원본영상 다운로드 | **사용자.** 다운로더는 내가 돌리지 않는다. 내가 링크만 정리해 준다 |
| 유튜브 등에서 내가 받아야 하면 | 파일명·출처·크기를 밝히고 **명시적 허락**을 받은 뒤에만 |
| 편집, 대본, 음성, 렌더, CapCut 프로젝트 | 나 |

## 1. 제품 파악 + 키워드
1. 쿠팡 링크를 브라우저 도구로 연다(`mcp__Claude_Browser__navigate`) → `get_page_text`로 상품명·가격·옵션 확인(이미지가 있으면 함께 본다).
2. 영어·중국어(간체)·일본어 검색 키워드를 뽑는다. 예: `flip top standing desk` / `翻盖升降桌` / `バブルガン`. 제품 특징 단어(숫자, 기능)를 넣는다.

## 2. 원본영상 링크 찾기
- 샤오홍슈: `https://www.xiaohongshu.com/search_result?keyword=<키워드>&source=web_search_result_notes` — 로그인 창이 뜨면 **사용자에게 QR 스캔을 요청**하고 로그인 확인 후 진행. 영상 탭(`视频`)에서 후보 확인.
- 틱톡: `https://www.tiktok.com/search/video?q=<키워드>` — 로그인 안 하면 "결과 없음"이 나온다 → 사용자 로그인 요청. 로그인 전 대안: `duckduckgo.com/html/?q=site:tiktok.com+"<키워드>"`로 공개 영상 링크 수집(Bing은 엉뚱한 결과가 나온다).
- 후보는 실제 열어서 **제품이 맞는지**(색상·모델) 확인한 뒤 링크 표로 사용자에게 준다. "다운로더에 붙여 넣어 드롭 폴더에 넣어 달라"고 안내하고 끝. 저작권/약관 주의를 한 줄 언급.

## 3. 클립 검수 (사용자가 폴더에 넣은 뒤)
1. `ffprobe`로 해상도·길이·오디오 유무 확인.
2. 컨택트시트로 훑는다: `ffmpeg -i clip.mp4 -vf "fps=1/2,scale=180:-2,tile=8x4" -frames:v 1 sheet.jpg` → Read로 본다.
3. 체크할 것: **제품 색상/모델이 쿠팡 제품과 같은가**(다르면 제외 또는 색이 안 드러나는 컷만), 고정 위치 외국어 자막·앱 UI·워터마크(→ 해당 구간 제외 또는 `crop`), 모션블러 프레임.
4. 크롭 위치는 해당 프레임 1장을 크게 뽑아 y비율을 확인(`crop:[y0,y1]`, 0~1). 자막이 시작 몇 초에만 있으면 그 구간을 피해 start를 잡는 게 화질에 유리.
   - **제품이 잘리는지 반드시 확인**: 자막 밑에 제품이 걸려 있으면(예: 책상이 화면 아래쪽) 위쪽만 남겨 확대하면 제품이 날아간다. 그럴 땐 제품이 있는 띠만 `crop:[y0,y1]`로 남기고 `"fit":"blur"`를 추가 → 띠를 가로 폭 그대로 두고 위아래를 블러 배경으로 채운다(썸네일 `thumb`에도 같은 옵션 사용 가능). 제품이 없는 클로즈업/소품 컷은 그냥 `crop`(cover-fit).
   - 워터마크가 화면 곳곳으로 움직이는 클립(샤오홍슈 다운로드본의 `@계정 | 小红书`)은 프레임 여러 장으로 위치를 확인하고, 크롭 띠를 그 밖으로 잡는다.
   - 밝은 원목·색상 등 **제품 사진과 다른 클립은 제외**(사용자가 "같은 제품이 아니야"라고 한 적 있음). 애매하면 쓴 클립과 이유를 보고한다.
5. 원본 소리는 항상 제거(`-an`). 클립이 모자라면 같은 클립의 다른 구간 재사용.

## 4. 대본 (정말정말 중요 — 사용자 상시 규칙)
제품명/쿠팡 정보만으로 전체 대본을 쓴다. 출력은 **순수 대본 줄만**(연출 지시·마크다운 없이).
- 15초 안팎, 구어체, 첫 3초 안에 훅, CTA 필수.
- **5단계**: ①잡아라(제품 말고 "무슨 일이 있었는지"로 시작) ②공감시켜라(일상 장면, 스펙 X) ③해결해라(사람이 알려주거나 우연히 써본 형태, 광고 멘트 X) ④'근데?'를 없애라(의심을 말하고 바로 답) ⑤행동시켜라(댓글에 '○○' 남겨주세요 → 정보/링크 안내).
- 9가지 심리 트리거 중 **2개 이상** 자연스럽게(손실회피·사회적증거·정체성·권위·궁금증·희소성·감정공감·미래의나·B급유머), 라벨 언급 금지.
- **금지 문구**: "후기 많은 이유 있어요", "지금 안 사면 품절이에요", "이거 모르면 손해예요" 및 유사한 압박/클리셰.
- 제품 사실(배터리, 수명 등)을 지어내지 않는다. 후기 톤 연출은 허용하되 최종 보고에서 "연출"이라고 밝힌다.
- 사용자가 대본을 직접 주면 그대로 쓴다(문장 끝 `. ? ~` 유지 — 자막 끊기에 사용). 숫자는 읽는 대로 적어도 됨(예: 백삼십이개).

## 5. 설정 JSON 작성 → 음성
`scripts/build_shorts.py` 상단 docstring 참고. 예:
```json
{"name":"desk_shorts_v1","workdir":"C:/CapCutAssets/desk_ad",
 "src_dir":"C:/Users/IdeaPad/Desktop/클로드 영상편집 자동화/쇼핑쇼츠/desk",
 "script":"문장1. 문장2? 댓글에 '책상' 남겨주세요~","post_tempo":1.06,
 "scenes":[{"clip":"파일명 일부","start":4.5,"cut_at":"그런데"}, {"clip":"...","start":6.0}],
 "thumb":{"clip":"...","t":7.5,"line1":"1줄","line2":"2줄"}}
```
```
python scripts/build_shorts.py voice config.json
```
- 음성은 **Kanna**(voice_id `5I7B1di44aCL15NkP0jn`, ElevenLabs API, 키는 `C:\Users\IdeaPad\Desktop\숏파인더 채널\_script\.env` — 내용을 출력하거나 다른 곳에 옮기지 않는다). 사용자가 유나를 원하면: 유나(`k5ki4ULQBrtjIPJSDMPA`)는 MCP 워크스페이스에 있는 별도 음성이라 이 API 키로는 안 된다.
- **발음 점검**: `voice`가 whisper가 들은 글자와 대본을 비교해 다르게 들린 단어를 `PRONUNCIATION CHECK`로 찍는다. Kanna는 의성어·의태어(예: "스르륵")를 어색하게 발음했고, 사용자가 그 단어를 음성·자막에서 잘라 냈다. 대본에 의성어/의태어는 피하거나 일반 단어로 바꾸고, 의심 단어는 사용자에게 들어 보라고 알린다.
- 무음 구간은 자동 제거(공백 없음). 속도: ElevenLabs 상한이 1.2라 기본 1.19 + ffmpeg `atempo`(`post_tempo`)로 추가 가속. "조금 더 빠르게" = post_tempo를 0.05~0.1씩 올린다.
- `whisper medium`(HF 캐시)로 단어 타이밍 → `workdir\caps.txt`에 자막 청크와 시간이 나온다. **이 파일을 Read해서 컷 지점을 정한다.**

## 6. 장면 짜깁기 규칙
- **장면(클립) 하나는 3초 이내이고, 그 안에 원본의 컷 전환이 1프레임도 없어야 한다**(사용자 규칙 — "그래야 보는 사람 눈이 안 아프다"). 대사 한 덩어리가 3초보다 길면 같은 대사 위에 장면을 여러 개로 쪼갠다.
  - 먼저 `python scripts/build_shorts.py shots config.json`으로 클립별 컷 구간(`0.00-2.47, 2.47-6.27 …`)을 확인하고, 장면 `start ~ start+길이`가 **한 구간 안에** 들어가게 잡는다(긴 구간이 있는 클립이 유리).
  - `build`가 이 규칙을 자동 검사해서 위반하면 위반 장면과 컷 시점을 알려 주고 중단한다(의도적으로 허용할 때만 장면에 `"allow_cut": true`).
  - **시작 지점은 원본 컷 전환에 정확히 맞춘다.** 장면 시작이 원본 컷 전환 직전(0.35초 이내)에 걸리면 앞 장면 몇 프레임이 섞여 들어간다(실제로 8.35초 시작이 8.53초 컷보다 0.18초 앞이어서 사용자가 8.53초로 고쳤다). `build`가 이런 시작을 전환 지점으로 자동 보정하고 `snapped` 로그를 남긴다. 끝이 컷 전환을 넘는 경우는 자동 보정하지 않고 위반으로 중단하니, 시작을 앞으로 당기거나 장면을 쪼갠다.
  - 사용자가 폴더에 넣어 둔 `…완성본.mp4`(본인 렌더)는 소스가 아니다. 사용자가 클립을 다시 편집해서 새로 넣을 수도 있으니 매번 `shots`/컨택트시트를 새로 뽑는다.
- **CapCut 프로젝트에는 원본 클립을 그대로 올린다**(`workdir\src\clipN.mp4`, 원본 전체 길이). 장면은 `source_timerange`로 구간만 잘라 쓰고, 크롭/줌은 CapCut의 scale·position 값으로 재현하며 원본 소리는 음소거한다. 그래서 사용자가 CapCut에서 클립 끝을 끌어 **늘리고 줄이거나 원본 어느 구간이든** 쓸 수 있다(미리 렌더한 짧은 컷 파일을 쓰지 않는다. `scene*.mp4`는 mp4 미리보기용).
- 대사와 화면이 어긋나면 안 되므로 **컷 지점은 대사가 바뀌는 자막 청크 시작**(`cut_at`에 그 청크의 글자 일부)에 맞춘다(길이가 균등하지 않아도 됨. 대사-화면 싱크 우선).
- 클립 순서는 원본 순서로 가지 말고 섞는다. 사건 → 공감 → 제품 클로즈업 → 사용 장면 → 결과(버블/효과) → CTA 순으로 대사에 맞는 컷을 고른다.
- 9:16이 아닌 소스는 cover-fit(중앙 크롭). 1080x1920, 30fps.

### 스타일 (고정)
- 자막: 화면 중앙, 흰색, 고딕(서울한강체 B), 크게, 2단어 Vrew식 짧은 버스트, 청크 사이 빈 구간 없음. 그림자: 검정 불투명도 100%·흐림 15%·거리 5%·각도 -45°, 테두리 얇게.
- 워터마크(사용자가 CapCut에서 직접 확정한 값): **배경 없음, 굵게 아님, 글자만 반투명.**
  - `[광고]`: 우상단(x 0.794, y 0.915), 크기 6·scale 1.105, 투명도 0.46.
  - `nanatem_shop`(샵 핸들, 기본 포함): **가로 중앙**(x 0, y -0.44 = 화면 아래쪽 중앙, 자막과 안 겹침), 크기 15·scale 0.74, 투명도 0.22.
- 썸네일: 영상 **맨 앞 1프레임**(나머지는 1프레임 뒤로 밀림). 제품이 히어로인 선명한 정면 프레임(모션블러·제품이 옆으로 잘린 프레임 금지), 제목 2줄, 1줄 흰색 / 2줄 `#bbffb4`, 위와 같은 그림자, 가로 중앙·세로는 중앙보다 위.
  - **폰트는 CapCut의 `카페24 단정해`**(resource_id `7528305055972199681`, 캐시 `Cache\effect\7528305055972199681\…\font.ttf`). 스크립트가 이 폰트를 지정하고 mp4용 썸네일도 같은 ttf로 그린다(코트라 볼드는 더 이상 쓰지 않는다).
  - 사용자 확정 배치: 1줄 크기 27·scale 0.805·y 0.559, 2줄 크기 25·scale 0.853·y 0.409(화면 위쪽 22~30%). CapCut에서는 **텍스트 레이어**(수정 가능)로 들어간다.
  - **제목은 두 줄이 이어서 한 문장으로 읽히는 구어체**로 쓴다(한 줄 8자 안팎, 사람이 말하듯 동사로 끝냄). 사용자가 직접 고친 예: "퇴근하면 책상도 / 닫아버려요". 사물을 나열하는 명사구("닫으면 사라지는 / 책상 위 잡동사니")는 피한다. 제목은 항상 2안 이상 제안하고 사용자가 CapCut에서 고치기 쉽게 한다.
  - **썸네일 배경 컷 고르는 법**: ① 제품/책상이 화면을 채우고 **동작(열리는·닫히는 순간, 사람이 쓰는 모습)이 보이는 컷**을 우선한다. 정지된 제품 사진 + 위쪽 절반이 빈 벽인 프레임은 피한다. ② 제목이 들어갈 **위쪽 22~30% 띠에는 제품·손동작이 없어야** 한다(벽·배경이 그 자리에 오는 컷). ③ 모션블러 없는 선명한 프레임, 고해상도(원본 그대로 확대가 심하면 크롭 줌이 적은 클립). 후보 프레임 4~6장을 컨택트시트로 뽑아 위 기준으로 고르고, 고른 이유를 보고에 한 줄 적는다.
- 새 CapCut 폰트가 필요하면(사용자가 앱에서 한 번 적용해 저장한 프로젝트에서) `Timelines\*\draft_content.json`의 텍스트 `fonts[]`(resource_id/path/title)를 읽어 스크립트 상수에 추가한다. 컴파운드 클립 안의 내용은 `materials.drafts[].draft`에 들어 있다.

### 외국어 자막 제거 (CapCut AI 제거)
- 사용자는 크롭 대신 **CapCut의 AI 제거(InPainting Erase)** 로 원본의 외국어 자막을 지운다. 이 기능은 앱 안에서만 돌아서 **내가 스크립트로 실행할 수 없다.**
- 자막이 있는 장면에는 `"erase": true`를 준다 → CapCut 프로젝트에는 크롭 없이 **전체 프레임**으로 올리고(원본 구간 그대로), `build` 출력에 **"CAPCUT AI 제거 needed on: 클립·구간·타임라인 위치"** 목록을 찍는다. 그 목록을 사용자에게 그대로 전달한다(사용자가 해당 구간에 AI 제거 적용).
- 같은 장면의 mp4 미리보기는 `crop`으로 자막을 잘라 낸 버전이다(미리보기 전용). 자막이 없는 장면은 `crop`만 쓰면 된다.
- 영어 자막처럼 화면 가장자리에 있는 경우 CapCut scale·position(줌+이동)으로 자막을 화면 밖으로 미는 것도 허용(사용자가 실제로 그렇게 했다).

## 8. 검증 (반드시)
1. `ffprobe`: 1080x1920, 길이 ≈ 음성+1프레임.
2. 프레임 샘플 컨택트시트를 Read로 확인: 썸네일 1프레임, **대사 ↔ 화면 싱크**, 자막 위치/그림자, 워터마크 2개, 크롭한 영상에 외국어 자막이 남았는지.
3. CapCut draft JSON 확인: 트랙 수, 자막 수, `has_shadow` 개수. (CapCut 앱에서 열어본 게 아니면 "열어보지 못했다"고 정직하게 보고.)
4. mp4·썸네일을 `완성본\`에 한글 이름으로 복사.

## 다른 PC(직원)에 배포하기
스킬 코드는 이제 경로를 `scripts/local_paths.json`(공유 안 함, git 무시 대상)에서 읽는다. 하드코딩된 값은 이 PC 전용 기본값일 뿐이다.

**보낼 것**: `C:\Users\IdeaPad\.claude\skills\shopping-shorts\` 폴더 전체를 압축(`SKILL.md`, `scripts\build_shorts.py`, `scripts\local_paths.example.json`) — **`local_paths.json`이 실제로 생겼다면 그 파일은 빼고** 보낸다(내 API 키 폴더 경로가 들어있음).

**받는 사람이 할 일**:
1. 압축을 자신의 `%USERPROFILE%\.claude\skills\shopping-shorts\`에 풀기 (Claude Code가 스킬을 찾는 표준 위치).
2. 미리 설치: Python 3 + `pip install pycapcut faster-whisper pillow requests`, `ffmpeg`(PATH에 등록), CapCut 데스크톱판.
3. 자기 ElevenLabs 계정 키 준비 — **이 PC의 `.env`를 공유하지 않는다.** 같은 키를 쓰면 요금이 이 계정으로만 청구된다. 직원 전용 폴더(예: 자기 Desktop 아래 아무 폴더)에 `elevenlabs_tts.py`(이 PC의 것을 복사)와 `.env`(본인 `ELEVENLABS_API_KEY=...`)를 넣는다.
4. CapCut에서 서울한강체 B와 카페24 단정해를 한 번씩 아무 텍스트에 적용해 로컬 캐시를 만든다(그래야 `Cache\effect\<id>\<hash>\font.ttf`가 생긴다).
5. `scripts\local_paths.example.json`을 `local_paths.json`으로 복사해 자기 경로로 채운다(각 필드 설명은 그 파일 안 `_..._설명`에 있음).
6. Claude Code에서 "쇼핑쇼츠 만들어줘"라고 하면 스킬이 잡힌다. 처음엔 `python scripts/build_shorts.py shots 아무설정.json` 같은 걸로 폰트/경로 오류가 없는지 확인해보게 한다(경로가 없으면 스크립트가 무엇을 못 찾았는지 바로 알려준다).
