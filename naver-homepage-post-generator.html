생성된 초안

입력을 완료하고 "초안 생성하기"를 클릭하면 여기에 초안이 나타납니다.

생성된 초안이 미리보기 영역에 표시됩니다.

✓ 제목과 본문 내용이 일치하는가?
✓ 제목의 궁금증이 본문에서 제대로 해소되는가?
✓ 확인되지 않은 내용을 사실처럼 쓰지 않았는가?
✓ 다른 블로거의 문장·사례·표현을 가져오지 않았는가?
✓ 내 경험이 아닌 내용을 경험한 것처럼 쓰지 않았는가?
✓ 민감한 내용의 사실관계를 확인했는가?
✓ 선정성이나 논란만을 노린 표현은 없는가?
✓ 사진·캡처 사용 권한과 출처를 확인했는가?
✓ AI 말투를 내 말투로 한 번 더 다듬었는가?
✓ 이 글을 내가 직접 발행해도 괜찮은가?
  • 첫 인상 체크: 첫 3~5줄을 읽고 독자가 계속 읽고 싶을까?
  • 구조 확인: 제목의 궁금증이 언제 회수되는가? 너무 길게 끌지 않는가?
  • 문장 길이: 한 문단이 5줄 이상이면 끊어서 가독성을 높여라
  • 소제목 활용: 소제목이 다음 내용을 자연스럽게 연결하는가?
  • 말투 통일: 처음부터 끝까지 톤이 일관되는가?
  • 구체성: 추상적 표현만 있지 않은가? 숫자, 사례, 구체적 액션이 있는가?
  • 마무리: 끝이 뚝 떨어지지 않고 자연스럽게 마무리되는가?
