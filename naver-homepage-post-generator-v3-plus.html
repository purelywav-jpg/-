🎯 절대 작성 규칙

• 검색자의 실제 궁금증을 먼저 해결합니다
• 실제 경험과 확인된 정보만 작성합니다
• 같은 내용을 반복하지 않습니다
• 과장, 허위 후기, 가짜 경험을 만들지 않습니다
• 제목과 본문의 내용이 정확히 일치합니다

📝 도입부 (첫 2~3문장)

• 검색자의 상황과 직접 연결하기
• 공감 → 이 글에서 얻을 정보 순서
• 공감형/경험형/반전형 등 다양하게

💡 정보 밀도

• 모든 문단에 새로운 정보를 넣습니다
• 구체적인 상황과 관찰 중심
• 의미 없는 표현(정말 좋아요) 최소화
• 400자마다 사진·인용구 배치

⭐ 차별성 (최소 2가지 포함)

• 실제 이용 상황
• 직접 확인한 특징
• 구체적인 비교
• 예상과 달랐던 부분
• 이용 팁
• 장점과 아쉬운 점

📏 길이

• 일반 글: 1,800~2,500자
• 정보성 글: 최대 3,000자
• 줄마다 15~18글자 기본
• 문단마다 정확히 4~5줄

🚫 금칙어 피하기

• 100%, 효능, 통증, 병원, 상담, 무료, 최고, 1위 등 금칙어 사용 금지
• 자연스러운 대체 표현 사용: 판매→제공, 가격→비용, 치료→관리

✍️ 최종 검수

• 금칙어 0개 확인
• 확인되지 않은 정보 없는지 확인
• 허위 경험·후기 없는지 확인
• 장점과 아쉬운 점 균형 맞는지 확인
• 광고 문구 과다 없는지 확인

생성된 원고

주제를 선택하고 "원고 생성" 버튼을 누르면
풍부한 내용의 원고가 여기에 나타납니다.
