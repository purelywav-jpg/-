크리에이터를 위한 클로드 코드 플러그인 5가지 설치 가이드

2026.09.02 · 브랜딩·수익화 컨설턴트 청정

콘텐츠를 매일 만들다 보면 반복 작업에 쓰는 시간이 생각보다 큽니다. 클로드 코드를 기본값 그대로 쓰고 있다면, 아래 5가지만 붙여도 토큰·기억·디자인·자동화 문제가 상당 부분 정리됩니다. 깃허브에 직접 들어갈 필요 없이 명령어를 복사해서 붙여넣는 수준이라 개발 경험이 없어도 따라할 수 있습니다.

시작 전에 확인할 것 — 어디서 쓸 수 있나

터미널에서 클로드 코드를 쓰면 5개 전부 쓸 수 있습니다. 클로드 웹이나 데스크탑 앱만 쓴다면 마지막 1개만 해당됩니다.

  • OmniRoute, claude-mem, Frontend Design, Playwright — 클로드 코드(터미널)에서만 동작
  • Task Observer — 웹, 데스크탑 앱, 모바일까지 전부 가능, 무료 요금제 포함

앞의 4개는 클로드 코드에 붙는 플러그인이라 웹이나 앱에는 설치할 자리 자체가 없습니다. Task Observer만 스킬 형태라서 어디서든 쓸 수 있습니다. 웹이나 앱만 쓰신다면 맨 아래 5번부터 보시면 됩니다.

시작 전에 준비할 것

  • Node.js 설치 (1번 OmniRoute에만 필요) — nodejs.org에서 LTS 버전을 받고, 설치 후 터미널을 껐다가 다시 켜야 인식됩니다.
  • 명령어 구분 — /로 시작하면 클로드 코드 안에서, / 없이 시작하면 터미널(명령 프롬프트)에서 입력합니다.

1. OmniRoute — 토큰 부족 시 다른 모델로 자동 전환

작업 중 토큰이 부족해지면 다른 모델로 갈아타서 이어가게 해주는 도구입니다. 내 컴퓨터에 작은 중계 서버를 띄우고 클로드 코드가 그쪽을 거쳐가도록 바꿔주는 방식으로 동작합니다.

  • 설치(터미널): npm install -g omniroute
  • 실행: 앞으로는 claude 대신 omniroute launch로 켭니다.
  • 확인: 브라우저에서 http://localhost:20128을 열어 대시보드가 뜨는지 봅니다. 터미널을 닫으면 서버도 같이 꺼집니다.

이 도구는 클로드 코드가 주고받는 트래픽을 로컬 서버가 중계하는 구조라, 회사 계정이나 민감한 프로젝트에서 쓰기 전에는 어떤 서버로 요청이 흘러가는지 문서에서 한 번 확인하고 쓰는 걸 권합니다.

2. claude-mem — 대화를 기억하는 기억 장치

클로드 코드는 창을 닫으면 이전 대화를 잊습니다. claude-mem을 붙이면 지난 작업 내용을 요약해 다음 대화에 자동으로 넣어주고, 예전에 뭘 했는지도 검색할 수 있습니다.

  • 설치(클로드 코드 안에서, 권장): /plugin marketplace add thedotmack/claude-mem 다음 줄에 /plugin install claude-mem
  • 대안(터미널): npx claude-mem install
  • 이건 피하세요: npm install -g claude-mem은 부품만 깔리고 기억 기능은 동작하지 않습니다.

회사 업무나 개인정보가 섞인 작업을 기록에 남기고 싶지 않다면, 공식 문서의 제외 설정을 먼저 확인하세요.

3. Frontend Design — AI 티 나는 화면에서 벗어나기

AI에게 화면을 맡기면 비슷한 보라색 그라데이션과 똑같이 생긴 버튼이 반복되기 쉽습니다. 앤트로픽 공식 플러그인으로, 글꼴과 색을 과감하게 골라줘서 어디서 본 듯한 느낌을 줄여줍니다.

  • 설치(클로드 코드 안에서): /plugin install frontend-design@claude-plugins-official
  • 명령어가 안 먹히면(터미널): claude plugin marketplace add anthropics/claude-plugins-official 실행 후 다시 시도합니다.
  • 확인: /plugin을 치면 설치 목록에 frontend-design이 보입니다.

따로 불러낼 필요 없이, 깔아둔 상태에서 평소처럼 “대시보드 만들어줘”, “랜딩페이지 만들어줘”라고 요청하면 자동으로 적용됩니다.

4. Playwright — 브라우저를 대신 조작

마이크로소프트가 만든 도구로, 클로드가 직접 브라우저를 열어 페이지를 돌아다니고 버튼을 누르고 스크린샷을 찍게 해줍니다. 내가 만든 화면을 직접 열어보고 이상한 곳을 찾아 고치는 것도 여기서 나옵니다.

  • 설치(클로드 코드 안에서): /plugin install playwright@claude-plugins-official
  • 안 되면 3번의 마켓플레이스 등록 명령을 먼저 실행하고 다시 시도합니다.

방금 만든 화면을 띄우고 “직접 열어보고 이상한 곳 고쳐줘”라고 시키는 게 체감이 가장 큽니다.

5. Task Observer — 반복 작업 자동 탐지 (웹·앱 가능)

옆에서 지켜보다가 매번 똑같이 시키는 일을 찾아내고, 한 번에 처리하는 방법을 먼저 제안해줍니다. 오래 쓸수록 시키는 말이 짧아집니다. 앞의 4개와 달리 플러그인이 아니라 스킬이라 설치 경로가 다릅니다.

  • 클로드 설정 → 기능에서 코드 실행을 먼저 켭니다. 이게 꺼져 있으면 스킬이 안 보입니다.
  • 커스터마이즈 → 스킬로 이동해 + 버튼을 누르고, 스킬 zip 파일을 그대로 올립니다(압축을 풀지 않습니다).
  • 코워크에서 쓸 때는 공유 폴더를 하나 정해서 계속 같은 폴더를 써야 이전 관찰 기록을 이어서 찾습니다.

세션을 마무리할 때 “관찰한 거 기록했어?”라고 한 번 물어보고, 시간이 지나면 쌓인 제안을 정기적으로 검토하는 방식으로 씁니다. 무료 요금제를 포함해 모든 요금제에서 됩니다.

도구는 작업 시간을 줄여줄 뿐, 무엇을 만들지 결정하는 건 여전히 사람의 몫입니다.

설치 전 체크리스트

  • 앤트로픽 공식 목록(claude-plugins-official)이 아닌 개인 저장소 기반 도구는 설치 전에 제작자와 소스 코드 저장소를 한 번 확인합니다.
  • 회사 계정, 고객 데이터, 민감한 프로젝트에서는 트래픽을 중계하거나 대화를 저장하는 도구부터 신중하게 검토합니다.
  • 처음에는 한 번에 다 깔지 말고 하나씩 붙여보면서 내 작업 방식에 맞는지 확인합니다.

콘텐츠 제작 워크플로우를 도구로 정리하고 싶다면, 1:1 컨설팅에서 우선순위부터 함께 잡아 드립니다.
