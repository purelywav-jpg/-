# 협찬/체험단 표기 문구 (sponsored-disclosure.md)

> 공정거래위원회 "추천·보증 등에 관한 표시·광고 심사지침" 기준. `/write` 마다 협찬 여부를 반드시 확인하고, 협찬이면 아래 중 대가 유형에 맞는 문구를 글 상단 첫 블록(`quote` 아닌 일반 `text`)에 기본 포함합니다. 업체 지정 문구가 있으면 그것을 우선합니다.

## 대가 유형별 문구

### 금전적 대가를 받은 경우
"이 글은 ○○(업체명)로부터 원고료를 지원받아 작성되었습니다."

### 제품/서비스를 무상으로 제공받은 경우 (체험단 등)
"이 글은 ○○(업체명)로부터 제품(서비스)을 무상으로 제공받아 직접 체험 후 작성한 후기입니다."

### 자사 상품/서비스를 직접 소개하는 경우
"이 글은 ○○(운영 업체)에서 직접 작성한 게시물입니다."

## 절대 금지
- 협찬·체험단 글에 "내돈내산", "광고 아님", "제가 직접 결제" 등 사실과 다른 부인 표현 사용 금지 (표시광고법 위반).
- 표기 문구는 본문 시작 부분에 위치해야 하며, 흐리게/작게/맨 아래 배치 등으로 눈에 띄지 않게 하는 것도 위반입니다.
