# 업종별 필수 촬영 컷 가이드 (photo-guide.md)

> `input/photos/` 에 사진을 넣을 때 참고할 체크리스트입니다. 업종을 인터뷰에서 확인한 뒤 해당 항목을 `profile.md` 에도 반영하세요.

## 공통
- [ ] 간판/외관 (검색자가 찾아올 수 있게)
- [ ] 작업/서비스 진행 장면
- [ ] 결과물/완성 컷

## 요식업 예시
- [ ] 외관·간판
- [ ] 메뉴판 (가격 확인용)
- [ ] 좌석/웨이팅 공간
- [ ] 메뉴별 클로즈업 (먹은 것 전부)
- [ ] 주차 안내판(있다면)

## 지역 서비스업 예시 (시공/수리/설치)
- [ ] 작업 전(Before)
- [ ] 작업 중
- [ ] 작업 후(After)
- [ ] 사용 장비/자재 클로즈업
- [ ] 명함/견적서(개인정보 없는 부분만)

## 뷰티/의료 예시
- [ ] 시술 공간 전경
- [ ] 사용 장비
- [ ] Before/After (동의 확인 필수 — `sponsored-disclosure.md` 및 개인정보 규칙 참고)

> 이 파일은 업종이 정해지면 Claude Code가 인터뷰 중 해당 업종 섹션을 추가/수정합니다.
