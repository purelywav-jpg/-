사용자가 붙여넣은 상위노출 블로그 글(들)을 분석해 다음 세팅값을 뽑으세요:

- 총 글자 수, 사진 수, 소제목 개수, 인용구 개수
- 제목 길이·구조 (키워드 위치, 특수문자 사용 여부)
- 키워드 반복 횟수(메인/서브)
- 발행 요일·시간대 (알 수 있는 경우)

결과를 `data/trends.md` 에 날짜와 함께 누적 기록하세요(기존 내용은 지우지 말고 추가, 평균값 갱신). 자동으로 웹을 크롤링해 수집하지 말고, 사용자가 이 명령에 직접 붙여넣은 글만 사용하세요.
