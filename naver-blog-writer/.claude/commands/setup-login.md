`node scripts/naver_login.js` 실행을 안내하세요. 이 스크립트는 브라우저를 직접 열어 사용자가 눈으로 로그인(비밀번호/2단계 인증/패스키 모두 가능)하게 하고, 완료 후 터미널에서 Enter를 누르면 세션을 `naver-profile/` 폴더에 저장합니다.

- 비밀번호는 저장되지 않으며, 세션 쿠키만 저장됩니다.
- `naver-profile/` 폴더는 `.gitignore` 에 포함되어 있어야 하고, 외부에 절대 공유하면 안 된다는 것을 사용자에게 상기시키세요.
- 로그인 후 블로그 글쓰기 화면(`https://blog.naver.com/`)까지 정상적으로 보이는지 확인시킨 다음 Enter를 누르게 하세요.
