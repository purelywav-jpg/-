사용자가 이 명령 뒤에 붙여넣은 블로그 글 본문을 분석하세요. (네이버 블로그 URL은 WebFetch가 도메인 차단으로 막힐 수 있으므로, 열리지 않으면 재시도하지 말고 바로 본문 붙여넣기를 요청하세요.)

추출할 것 (문장을 그대로 베끼지 말고 "구조"만 — 유사문서 위험 방지):

- 도입부 후킹 패턴 (손실회피형/현장몰입형/반전형/공감형 중 무엇인지)
- 문단 리듬 (문장 길이, 블록 길이, 인용구/구분선 삽입 빈도)
- 권위 제시 방식
- 마무리·CTA 방식
- 전반적 말투 (존댓말 수위, 이모지 빈도, 어미 패턴)

결과를 `data/style-profile.md` 에 날짜와 함께 누적 기록하세요(기존 내용은 지우지 말고 추가). 이미 기록된 패턴과 겹치면 "반복 확인됨"으로 표시해 신뢰도를 높이세요.
